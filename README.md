## CPU 有多少種類型（架構）
1. x86 架構
   - 代表廠商：Intel、AMD
   - 主要用途：桌上型電腦、筆記型電腦、伺服器
   - 優點：效能強、軟體相容性佳
2. ARM 架構
  - 代表廠商：Apple、高通(Qualcomm)、聯發科(MediaTek)
  - 主要用途：手機、平板、嵌入式系統、部分筆電
  - 優點：低功耗、省電
3. RISC-V 架構
  - 新興開源架構
  - 主要用途：物聯網、嵌入式系統、AI晶片
  - 優點：開源、授權成本低
  - 未來發展潛力大
4. 其他較少見架構
