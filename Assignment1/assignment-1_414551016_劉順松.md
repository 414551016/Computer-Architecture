````text
### General Principles for Optional Dates and Short-Circuit Evaluation

1. **Avoid Incompatible Comparisons:** In Python, comparing `None` with a `datetime.date` object using relational operators (e.g., `<` or `>`) raises a `TypeError`. Any optional field must be verified as non-`None` before performing a comparison.
2. **Use Short-Circuit Evaluation:** Boolean expressions evaluate left-to-right and stop as soon as the outcome is determined. Placing `task["due_date"] is not None` before the relational check `task["due_date"] < current_date` ensures that Python only evaluates the comparison when `due_date` contains a valid date object.

---

### Application to `get_overdue_tasks`

In `get_overdue_tasks`, tasks created without a `due_date` default to `None`. Evaluating `task["due_date"] < current_date` raises a `TypeError` on those undated tasks.

To fix this while keeping incomplete tasks with dates strictly before `current_date` and excluding undated tasks, update the condition to check that `due_date` is not `None` first:

def get_overdue_tasks(tasks, current_date):
````

````text
def sort_tasks_by_priority(tasks):
````

````text
* **Verdict:** PASS
* **Reason:** `priority_order = {"high": 0, "medium": 1, "low": 2}` assigns lower numerical ranks to higher priorities. In Python's tuple comparison, lower integers are sorted first (`0 < 1 < 2`), ordering tasks as high, medium, then low.


2. **Ascending dates within each tier**
* **Verdict:** PASS
* **Reason:** For tasks with a valid `date` object, `due_key` evaluates to `(0, due)`. Python compares `(0, date_A)` vs `(0, date_B)`, where `date_A < date_B` correctly places earlier dates before later dates.
````

````text
        list: The updated list of tasks.
````

````text
To determine which tasks are urgent and how to sort them, we should establish a clear urgency model based on your task structure:

1. **Urgent Definition:** A task is urgent if it is **uncompleted** (`completed` is `False`), has a **due date**, and is due **on or before** `today` (i.e., overdue or due today).
2. **Sort Order (Most Urgent First):**
* **Due Date (Ascending):** Tasks due earlier (or more severely overdue) come first. Tasks without a due date are excluded from urgency.
* **Priority Tier (Descending):** If due dates are equal, `"high"` priority precedes `"medium"`, which precedes `"low"`.



Here is the implementation:

```python
def get_urgent_tasks(tasks, today):
    """Return a list of incomplete tasks due on or before today, sorted by most urgent first.

    Urgency criteria:
    1. Due date (earlier/overdue dates come first).
    2. Priority ("high" > "medium" > "low").

    Args:
        tasks (list): List of task dictionaries.
        today (date): The reference date to evaluate urgency against.

    Returns:
        list: Sorted list of urgent task dictionaries.
    """
    priority_map = {"high": 0, "medium": 1, "low": 2}

    urgent = [
        t for t in tasks
        if not t.get("completed")
        and t.get("due_date") is not None
        and t["due_date"] <= today
    ]

    urgent.sort(
        key=lambda t: (
            t["due_date"],
            priority_map.get(t.get("priority", "medium"), 1)
        )
    )

    return urgent

```
````

````text
from datetime import timedelta, date

def get_urgent_tasks(tasks, today):
    """Retrieve and sort urgent tasks that are incomplete.

    Args:
        tasks (list): A list of task dictionaries, each containing 'title',
            'due_date', 'priority', and 'completed' keys.
        today (date): The current reference date.

    Returns:
        list: A new list of urgent task dictionaries sorted by due date, with
            undated high-priority tasks placed last.
    """
    if not tasks:
        return []

    threshold = today + timedelta(days=3)
    urgent_tasks = []

    for task in tasks:
        if task.get("completed"):
            continue

        priority = task.get("priority")
        due_date = task.get("due_date")

        is_high = priority == "high"
        is_due_soon = due_date is not None and due_date <= threshold

        if is_high or is_due_soon:
            urgent_tasks.append(task)

    def sort_key(task):
        due = task.get("due_date")
        if due is None:
            return (1, date.max)
        return (0, due)

    return sorted(urgent_tasks, key=sort_key)
````
